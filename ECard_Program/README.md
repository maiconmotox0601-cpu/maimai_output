# ECard Program
Google Colab で作成したカードゲームの練習プログラムです。
このプログラムは、プレイヤーとコンピュータが
「王・勇者・ドラゴン」の3種類のカードを使って対戦する
全5ラウンドのカードバトルゲームです。
各ラウンドで勝敗を判定し、最終的な勝ち数に応じて
あなたの勝ち・負け・引き分けを表示します。

## 機能
・プレイヤーとコンピュータのカード対戦

・3種類のカードによる勝敗判定

・ランダムなカード選択（コンピュータ側）

・プレイヤー・コンピュータの勝ち数カウント

・途中でゲームを中断できる機能（y/n）

・最終結果の表示（勝ち／負け／引き分け）

## ルール
カードの強さ関係は以下の通りです：

・王 は 勇者 に勝つ

・勇者 は ドラゴン に勝つ

・ドラゴン は 王 に勝つ

・同じカード同士 → 引き分け

## 使い方
1．プログラムを実行すると、1〜5回戦が順番に開始されます。

2．各ラウンドの冒頭で

コード
途中でやめますか？（y/n）:
と表示されます。

y → ゲームを中断

n → 続行

3．続行すると、あなたのカードを入力します。

4．コンピュータのカードがランダムに選ばれ、勝敗が判定されます。

5．5ラウンド終了後、最終的な勝ち数と総合結果が表示されます。

## 実行例
--- 1回戦 ---

途中でやめますか？（y/n）: n

あなたのカードを選んでください（王・勇者・ドラゴン）: 王

コンピュータのカード: 勇者

あなたの勝ち！

--- 2回戦 ---

途中でやめますか？（y/n）: y

ゲームを中断しました。


最後まで続けた場合：

ゲーム終了！

あなたの勝ち数: 3

コンピュータの勝ち数: 2

あなたの勝ちです！

## メモ
・入力は小文字・大文字どちらでも判定できるよう lower() を使用しています。

・中断時は break によりループを抜けるため、最終結果表示はスキップされます。

・標準ライブラリのみで動作します（追加インストール不要）。

・カードの強さ関係は辞書で管理しており、拡張が容易です。
