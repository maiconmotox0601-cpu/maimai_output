# Fruit Price Checker
果物名を入力すると価格を表示する、シンプルな辞書検索プログラムです。
辞書に存在しない名前を入力した場合は「データがありません。」と表示されます。
0 を入力すると終了します。

## 機能
・果物名を辞書から検索
・該当データがあれば価格を表示
・データがなければメッセージ表示
・0 で終了

## 使い方
python hello.py_v2
果物名を入力すると価格が表示されます。
