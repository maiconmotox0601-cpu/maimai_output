# shopping_list
このプログラムは、ユーザーが入力した商品名をリストに追加し、
最後にまとめて表示する シンプルな買い物リスト作成ツールです。
0 を入力すると商品入力が終了し、現在のリストが表示されます。

## 機能
・商品名を1つずつ入力してリストに追加

・0 を入力すると入力終了

・入力された商品を リスト形式でまとめて表示

## 使い方
1．プログラムを実行すると、商品名の入力を求められます。

2．商品名を入力すると、リストに追加されます。

3．商品入力を終えたい場合は 0 を入力します。

4．最後に、追加された商品リストが表示されます。

## 実行例
商品名を入力してください(終了は0)：りんご

商品名を入力してください(終了は0)：牛乳

商品名を入力してください(終了は0)：パン

商品名を入力してください(終了は0)：0

['りんご', '牛乳', 'パン']

## メモ
・商品は append() によってリストに追加しています。

・終了判定は文字列 "0" で行っています。

・入力された順番のままリストが表示されます。
