# Word Counter
このプログラムは、Google Colab で作成したテキスト解析ツールです。
ユーザーが入力した文章を解析し、単語数・ユニーク単語数・ソート済み単語一覧・特定単語の出現回数を
簡単に確認できます。

文章を小文字化し、空白区切りで単語を抽出することで、
シンプルかつ扱いやすい形でテキストを処理します。

## 機能
・入力した文章を 小文字に統一

・空白区切りで単語を抽出

・総単語数 の表示

・ユニーク単語数 の表示

・ユニーク単語を アルファベット順にソートして一覧表示

・任意の単語の 出現回数をカウント

## 使い方
1．プログラムを実行すると、文章の入力を求められます。

2．入力した文章は自動的に小文字化されます。

3．空白区切りで単語が抽出され、

単語数

ユニーク単語数

ソート済み単語一覧
が表示されます。

4．最後に、出現回数を調べたい単語を入力すると、
その単語が文章中に何回登場したかが表示されます。

## 実行例
文章を入力してください：I love Python and I love coding.

単語数： 6

ユニークな単語数： 4

単語一覧（ソート済み）：

- and
- coding.
- i
- love
- python

出現回数を調べたい単語を入力してください：love

「love」の出現回数： 2

## メモ
・文字列はイミュータブルのため、lower() の結果は必ず再代入しています。

・単語の抽出は split() による 空白区切り のみで行っています。
句読点を除去したい場合は追加処理が必要です。

・ユニーク単語は set() によって重複を自動で除去しています。

・ソートは sorted() による アルファベット順 です。

・出現回数のカウントは words.count(target) を使用しています。
